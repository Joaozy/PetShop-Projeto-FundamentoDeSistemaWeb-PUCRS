# 🐶 PETSHOP ANIMALE - PROJETO DA DISCIPLINA (FASE 1)

## 📍 Objetivo do Projeto
Desenvolver a estrutura básica em **HTML puro** do front-end de uma plataforma online de comércio de produtos e serviços para um petshop. Este documento refere-se à **Fase 1** do projeto, focada na estruturação sem customizações visuais (CSS) ou lógicas (JavaScript).

## 🔗 Acesso ao Site (Publicação Web)
O site pode ser acessado no seguinte endereço:
https://joaozy.github.io/PetShop-Projeto-FundamentoDeSistemaWeb-PUCRS

---

## ✨ Funcionalidades da Página Web (Fase 1)

A página atual (`index.html`) apresenta as seguintes funcionalidades estáticas:

| Seção | Funcionalidades Implementadas |
| :--- | :--- |
| **Cabeçalho (Header)** | Apresentação do nome do Petshop e links de navegação (*placeholders*). |
| **Produtos** | Visualização de **6 produtos**, sendo 2 de cada categoria. |
| **Categorias** | 1. **Acessórios** (Ex: Cama, Brinquedo) |
| | 2. **Rações Não Perecíveis** (Ex: Ração Cães, Ração Gatos) |
| | 3. **Higiene e Limpeza** (Ex: Tapete, Shampoo) |
| **Detalhes dos Produtos** | Cada produto exibe **Imagem**, **Descrição** e **Valor**. |
| **Serviços** | Visualização dos serviços de **Banho e Tosa**. |
| **Rodapé (Footer)** | Informações de contato, autoria legal, termos de uso e política de privacidade. |
